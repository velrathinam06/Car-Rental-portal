# Car Rental Portal

## Project Description
The Car Rental Portal is a web-based application designed to allow users to browse, book, and manage rental vehicles online.

## Figma Prototype
https://www.figma.com/proto/tYdwHrcRM91nk0Al0X146n/Car-Rental-Portal?node-id=0-1&t=YKFyD4kEbzRRc7Ut-1

## Features
- User Registration
- User Login
- Vehicle Search
- Vehicle Booking
- Booking Management
- Admin Dashboard

## Technologies Used
- Figma (UI/UX Design)
